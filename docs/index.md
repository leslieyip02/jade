# Jade Documentation

Jade is a Java decompiler that aims for high reliability through extensive
testing.

Use the navigation to find project documentation, or open the generated [API
reference](https://leslieyip02.github.io/jade/api/index.html) for Kotlin and
Java API details.

## Getting Started

Generate a runnable distribution with:

```sh
./gradlew installDist
```

See the [usage guide](USAGE.md) for command-line examples and the
[developer guide](developer-guide.md) for working on Jade.
